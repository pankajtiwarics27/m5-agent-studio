# Choosing a recorded artifact for feedback

The evidence panel now offers a native, labelled chooser for up to 20 versions recorded by the selected session's latest checkpoint. It names the artifact and a digest prefix; the feedback composer shows the full content digest. More than 20 versions are explicitly reported as truncated. The selected identity and drafts are remembered only in page memory. When the previously selected version is no longer in the displayed list, the panel requires a new choice instead of silently binding to another version.

The browser checks that the returned version list and checkpoint agree on session, artifact IDs and content digests and refuses contradictory or malformed data. This is a client-side consistency check, not server authorization or a current-content recheck. Diff rows remain inert and submissions remain artifact-level. Precise region selection and server-side verification of caller-supplied artifact identities remain open in [issue 413](https://github.com/pankajtiwarics27/m5-agent-studio/issues/413). A page reload loses in-memory selection and drafts. An in-flight submission may still succeed after navigation.

The real browser feedback walk passed 65/65 checks, including choosing a second checkpoint artifact, reopening its draft, and checking that the actual persisted feedback belongs to that artifact rather than the first. A focused VM probe exercises malformed checkpoint data, stale reads and writes, bounded options and missing selections. Twenty-one targeted frontend mutations were caught by that probe. Browser mutations caught missing second fixture, incorrect binding and posting, lost draft, missing reopen preference, horizontal overflow and clipped content. The required browser wrapper passed all six walks; its outdated feedback-count mutation failed and the restored test passed. The focused feedback, reference, recovery, presentation and keyboard suite passed 167 tests.

Refreshed source-bound accessibility and performance checks passed 120/120 and 21/21, and the cross-tab walk passed 2,200/2,200 checks across 48 captures. Backend safety passed 309 tests and 16 isolation checks, with isolation unqualified and blocked. The historical release gate passed 37/37 artifact checks and 7/7 phase gates; historical preservation approval remains unbound, and UIV2-30 release review remains stale or blocked. These checks do not establish human visual or screen-reader acceptance, server trust, or pilot qualification.
