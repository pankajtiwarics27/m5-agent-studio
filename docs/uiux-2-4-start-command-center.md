# Start: the command center

Generated by `python3 scripts/uiux_start_command_center_inventory.py` — **never hand-edit this page**.

Start opens with the one action it exists for - opening a task - followed by one sentence of verdict and at most one blocker, with the checklist, health and workspace one disclosure below. The verdict is the server's, printed with the basis it was reached on, and a port that answers without a model is a contradiction with its evidence rather than a green word.

## What the pane is now

| Position | Surface | Why there |
|---|---|---|
| 1 | **New task** composer + the readiness sentence + at most one blocker | the one action the pane exists for, with the answer to *can I start?* directly above the input and the obstacle directly below it |
| 2 | **Recent work** | the sessions a reader is most likely to want back, read from the Harness's own endpoint |
| 3 | **Readiness details** (collapsed) | the six-step checklist, the lead, the guided first task, and the basis line |
| 4 | **System health** (collapsed) | the four measured rows, their basis, and the re-check |
| 5 | **Project workspace** (collapsed) | the directory the task will run in, set through the same saver as the Harness |

Each disclosure is a native `<details>`/`<summary>`, so it is toggled by keyboard and announced as a disclosure rather than as a card with hidden contents. Each summary carries the state of what is inside it: a collapsed checklist still shows its verdict pill, and a collapsed workspace still shows whether a directory is set. A failing check hidden behind the word *details* would be a hidden requirement.

## The verdict, and the basis it stands on

| Verdict | Meaning |
|---|---|
| `ready` | every preflight step reads ready **and** nothing contradicts it |
| `needs-you` | a step is waiting on the reader; `next` names it and its action |
| `blocked` | a step will not clear on its own |
| `contradiction` | two honest observations disagree; `contradictions` prints both and the evidence |

The basis is printed next to the verdict, because the sentence *Ready to run* is only true in the sense it was measured:

- **measured** — the runtime was asked and answered (`port_answered` plus the `model_count` it reported);
- **derived** — nothing was asked, so the verdict rests on local configuration alone and the line says *runtime not asked*.

A port that answers with an empty model list is a **contradiction** (`port-without-models`), never a ready: the socket is up and a turn would still fail. The same applies to models the check cannot use (`runtime-models-without-usable-selection`), to checks that passed while the runtime stayed silent (`checks-passed-without-runtime`), and to the demo health payload sitting beside a live probe (`demo-health-with-live-runtime`).

## Rules this artifact enforces

`--check` fails when the composer is not the first card or not the primary action, when the verdict is printed below the composer it describes or the blocker above it, when the checklist is not behind a disclosure, when a disclosure starts open or its summary stops carrying its state, when the pane stops printing the server's headline/counts/basis/runtime evidence, when it computes a verdict of its own or reads the preflight directly a second time, when a contradiction loses its evidence, its `role="alert"` or its action, when the workspace blocker no longer opens the workspace control on this pane, when a probe starts happening on render, and when a port that answered without models is called ready.

## Checks and limits

- the matrix runs the pure module, so it covers every runtime observation the pane can hold but not the live probe against a real runtime.
- a browser cannot make a machine ready, so scripts/start_walk.mjs asserts the pane against the same API response it received rather than against an invented ready state.
- the contradiction that needs a real empty runtime is covered by tests/test_start_command_center.py, which stubs the probe to answer with zero models.
- keyboard reachability of the disclosures is proved in the walk (native <summary>), not in this artifact.
