## Panes in this build

| Tab | Pane | What it is for |
|---|---|---|
| `start` | Start | Guided first run: the preflight checklist and one-click next actions. |
| `harness` | Harness | Agent sessions over a workspace, with diffs, approvals, and abort. |
| `hall` | Council | Multi-model sessions that keep a visible, append-only discussion. |
| `council` | Pipeline | A four-stage pipeline for a single request. |
| `debate` | Compare | The same prompt against several models, side by side. |
| `chat` | Chat | One model, one conversation, streaming. |

## Reproducing

```bash
python3 scripts/demo_tour.py            # print the tour
python3 scripts/demo_tour.py --write    # regenerate this file
python3 scripts/demo_tour.py --check    # fail if it drifted
```

The tour never reuses your real database. See `docs/demo.md` for the walkthrough
and for how the screenshots are captured.
