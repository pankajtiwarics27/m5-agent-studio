# Benchmark publication inputs

`benchmark-config.example.json` is a run-plan template, not a result. Edit the
methodology, repetition counts, and caveats for the measurements being
published; do not treat its example values as a result or as physical-device
evidence.

There are currently **no checked-in raw target-runtime benchmark results**.
AS-023's hardware validation harness is covered by tests, but representative
runs on physical 16/24/48 GiB machines remain outstanding. This directory will
hold publication bundles only after reviewed, integrity-valid AS-059 raw
profiles are explicitly supplied; no synthetic result is substituted for that
evidence.
